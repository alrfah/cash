# ربط الحوالات الآمن — الرفاه كاش

تم تجهيز الواجهة لاستدعاء دالة Firebase Callable باسم `transferFunds` بدل الكتابة المباشرة من المتصفح.

## الملفات

- `الرفاهكاش-firebase-transfers-fixed.html`: نسخة الواجهة المرتبطة بالدالة.
- `functions/index.js`: الدالة الآمنة التي تتحقق من المستخدم والرصيد وتنفذ الخصم والإضافة وتكتب سجل `tx` وتنشئ إشعار المستلم.
- `functions/package.json`: حزم الدالة.
- `firebase.json`: إعداد مصدر الدوال فقط.

## النشر

من مجلد المشروع الذي يحتوي على هذه الملفات:

```bash
cd functions
npm install
cd ..
npx firebase-tools deploy --only functions:transferFunds --project alrfah-cash
```

هذا النشر لا يعدّل قواعد Realtime Database ولا يحذف أو يغيّر أي بيانات موجودة. بعد نشر الدالة، ارفع ملف HTML إلى الاستضافة نفسها التي تستخدم Firebase، ثم جرّب حوالة بين حسابين.

تقوم الدالة بعد نجاح الحوالة بـ:

1. خصم المبلغ من حساب المرسل.
2. إضافة المبلغ إلى حساب المستلم.
3. تسجيل العملية داخل `tx` ليشاهدها الطرفان في آخر التحويلات وقسم التحويلات.
4. إنشاء إشعار داخل `userNotifications` للمستلم.
5. إعادة بيانات الإيصال للمرسل، بينما يصل نفس سجل العملية للمستلم لفتح الإيصال بالضغط المطول.
